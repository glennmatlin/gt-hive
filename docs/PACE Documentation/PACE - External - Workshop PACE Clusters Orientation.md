# PACE - External - Workshop: PACE Clusters Orientation

---

## Introduction to PACE

## Overview

PACE Clusters Orientation provides new or existing users with the fundamental information needed to get started using PACE clusters, including Phoenix and Firebird. We strongly encourage all PACE users to attend at least one of these classes. To make Orientation accessible to the broadest audience, it is offered in both live interactive sessions and in a series of recorded videos.

The topics covered by this workshop include:

-   What is PACE?
-   Understanding the purpose of the different PACE clusters
-   How to request an account and access PACE clusters
-   Understanding the process of job submission
-   Transferring data to/from PACE-managed clusters
-   How to utilize the PACE-provided software stack via modules
-   Submitting and monitoring jobs using the Slurm Workload Manager
-   Requesting special/specific resources
-   Understanding resource usage
-   Where and how to get help

**Prerequisite:** This workshop is designed for complete beginners who are interested in utilizing PACE’s resources for their research or project. No prior experience is required. 

**Format:**

-   **Duration:** 1 hour and 45 minutes
-   **Delivery:** Live instructor-led via Zoom **OR** series of recorded videos
