## Introduction to Code Optimization

## Overview

In this instructor-led course, we will explore topics like benchmarking, profiling, and optimization by working through a serial linear algebra problem. We will use a problem-directed approach, focusing on matrix multiplication in the context of systems of linear equations solvers.

The topics covered by this workshop include:

-   What is optimization?
-   Benchmarking
-   Profiling
-   GDB
-   Intel Amplifier
-   DDT
-   TAU
-   Optimization using compiler options
-   Optimization using algorithm changes

**Prerequisite:** The course is recommended for researchers with a background in compiled languages such as C/C++ or Fortran. Familiarity with a programming language such the attendee will be able to read follow code with guidance. Great familiarity is encourages, but **not** required. 

**Format:** 

-   **Duration:** 1 hour and 45 minutes
-   **Delivery:** Live instructor-led via Zoom with a presentation and hands-on demonstrations.
