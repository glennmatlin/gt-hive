# PACE - External - Workshop: Linux 101

---

## Introduction to Linux

## Overview

This is an introductory course in Linux. It is recommended for anyone new to the Linux environment, especially if you are a PACE user.

The topics covered by this workshop include:

-   An explanation of the Linux OS and why it is useful
-   How to access a remote cluster (e.g. PACE-ICE) using OpenSSH
-   Introduction to working with the terminal and Bash
-   Filesystem navigation and file management in Linux using Bash commands
-   Understanding and utilizing environment variables
-   Automation with Bash scripting
-   Customization of Linux sessions

**Prerequisites:** The workshop is designed for complete beginners, so no prior Linux experience is required. Familiarity with using a terminal or command line is helpful but not required. Please install and connect to Georgia Tech’s PaloAlto/Global Protect Client VPN prior to the workshop. More information is available [here](https://gatech.service-now.com/home?id=kb_article_view&sysparm_article=KB0042139).
